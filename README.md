# SplitMate

Telegram Mini App MVP для разделения расходов между друзьями.

## Что умеет

- создавать событие поездки, кафе или общего подарка;
- добавлять участников;
- добавлять расходы с плательщиком;
- выбирать, между кем делить конкретный расход;
- считать баланс каждого участника;
- упрощать долги до минимальных переводов;
- копировать итоговое сообщение для Telegram-чата.

## Стек

- Next.js App Router
- TypeScript
- Tailwind CSS
- lucide-react
- Telegraf
- dotenv

## Запуск Mini App frontend

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Запуск Telegram-бота

1. Создайте бота в Telegram через `@BotFather`.
2. Скопируйте токен бота.
3. Создайте `.env` по примеру `.env.example`.
4. Заполните `BOT_TOKEN`.
5. Заполните `BOT_USERNAME`, если нужна кнопка добавления бота в группу.
6. Пока Mini App не задеплоен, оставьте `MINI_APP_URL=http://localhost:3000`.

```bash
npm run bot
```

Для разработки с автоперезапуском:

```bash
npm run dev:bot
```

## Команды бота

- `/start` — главное меню с кнопкой открытия SplitMate;
- `/app` — кнопка открытия Mini App;
- `/new Поездка в Алматы` — создать расчёт прямо в Telegram;
- `/people Амир, Али, Даник` — добавить участников;
- `/add 12000 Амир такси` — добавить расход;
- `/expenses` — показать список расходов;
- `/balance` — посчитать баланс и переводы;
- `/split 12000 3 такси` — быстрый расчёт прямо в чате;
- `/group` — инструкция для группового чата;
- `/summary` — пример итогового расчёта;
- `/reset` — сбросить текущий расчёт;
- `/help` — помощь.

Мини-сценарий без Mini App:

```text
/new Поездка в Алматы
/people Амир, Али, Даник
/add 12000 Амир такси
/add 7800 Али кофе
/balance
```
